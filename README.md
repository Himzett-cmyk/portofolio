## Apa Ini?

Portfolio pribadi. Gak dibuat buat kesan formal atau kejar validasi — cuma tempat pamer project dan progress belajar ngoding. Ngoding di sini kapan mood aja, gak dipaksa-paksa jadwal.

Tema visual: **brutalism** — hitam-putih, border tebal, gak ada sudut membulat. Kalau lo cari desain yang "aman" dan rapi kayak website perusahaan, ini bukan tempatnya.
